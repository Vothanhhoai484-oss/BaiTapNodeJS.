**2. Nội dung thực hiện**

- Sử dụng module `http` có sẵn trong Node.js.
- Tạo HTTP Server chạy tại cổng 3000.
- Xử lý yêu cầu truy cập trang chủ.
- Trả về trang HTML có họ tên và mã sinh viên.
- Thiết kế giao diện HTML bằng CSS.

**3. Cách chạy chương trình**

Bước 1: Mở thư mục dự án bằng Visual Studio Code.

Bước 2: Mở Terminal và nhập:

`node server.js`

Bước 3: Mở trình duyệt và truy cập:

`http://localhost:3000`
