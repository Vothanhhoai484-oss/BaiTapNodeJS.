# BÀI THỰC HÀNH NODE.JS – TẠO HTTP SERVER

**1. Thông tin sinh viên**

- Trường: Kỹ thuật Công nghệ Nha Trang
- Họ và tên: Võ Thanh Hoài
- Lớp: CĐ-CNTT18A
- Mã sinh viên: CĐ-CNTT18A14

**2. Nội dung thực hiện**

- Sử dụng module `http` có sẵn trong Node.js.
- Tạo HTTP Server chạy tại cổng 3000.
- Khi truy cập trang chủ, server trả về nội dung HTML.
- Trang HTML hiển thị họ tên và mã sinh viên.
- Có thể truy cập ứng dụng tại `http://localhost:3000`.

**3. Công nghệ sử dụng**

- Node.js
- JavaScript
- HTTP module
- HTML và CSS

**4. Hướng dẫn chạy chương trình**

Bước 1: Cài đặt Node.js.

Bước 2: Mở thư mục dự án `BaiTapNodeJS` bằng Visual Studio Code.

Bước 3: Mở Terminal tại thư mục dự án.

Bước 4: Chạy lệnh:

`node server.js`

Bước 5: Mở trình duyệt và truy cập:

`http://localhost:3000`
